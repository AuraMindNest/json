= 快速浏览
在此我们通过示例代码重点介绍重要特性，以帮助理解接口风格。首先包含库头文件，该文件将所有符号引入作用域。或者，也可以包含单独的头文件以获取特定类型的声明：

[source]
----
#include <boost json.hpp="">
</boost>----

为链接程序，您需要链接已构建的库。或者，您可以使用仅需头文件的配置，只需在任意一个新建或现有源文件中包含此头文件：

[source]
----
#include <boost json="" src.hpp="">
</boost>----

[NOTE]
====
文中所使用的示例代码和标识符均假定以下声明已生效：

[source]
----
#include <boost json.hpp="">
using namespace boost::json;
</boost>----
====
