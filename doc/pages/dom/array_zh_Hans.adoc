== 格式化输出

当 &lt;<ref_array>&gt; 被格式化输出到 {std_ostream} 时，结果是一个有效的 JSON。也就是说，该数组将按照 JSON 规范，以方括号和逗号分隔的值列表的形式输出。</ref_array>
