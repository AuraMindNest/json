= 直接转换
对于大型输入，先解析到库的容器中，然后通过&lt;<ref_value_to>&gt;进行转换（或反之，先通过&lt;<ref_value_from>&gt;转换，然后从&lt;<ref_value>&gt;序列化）可能代价过高。对于这些情况，库提供了允许直接解析到用户提供的对象以及直接从用户提供的对象序列化的组件。</ref_value></ref_value_from></ref_value_to>

这种方法的缺点是它不支持完全自定义的类型表示，仅支持库提供的转换。此外，所有需要通过解析填充的对象都必须是默认可构造的类型。这不仅包括顶层对象，还包括例如容器的元素、所描述`struct`的成员以及变体类型的备选项。

话虽如此，如果你的类型是默认可构造的，并且不需要&lt;<ref_value_to>&gt;和&lt;<ref_value_from>&gt;所允许的自定义能力，那么通过直接转换你可以获得显著的性能提升。</ref_value_from></ref_value_to>

直接解析由&lt;<ref_parse_into>&gt;系列函数执行。库提供了接受&lt;<ref_string_view>&gt;或`std::istream`的重载，并且可以通过抛出异常或设置错误码来报告错误。</ref_string_view></ref_parse_into>

如果需要将增量解析与直接解析结合使用，可以借助&lt;<ref_parser_for>&gt;。`parser_for<t>`是&lt;<ref_basic_parser>&gt;的一个实例化，它解析到类型为`T`的对象中，并且是&lt;<ref_parse_into>&gt;在底层所使用的。</ref_parse_into></ref_basic_parser></t></ref_parser_for>

直接序列化不需要任何特殊组件，并且可以与常规的&lt;<ref_serializer>&gt;和&lt;<ref_serialize>&gt;一起工作。</ref_serialize></ref_serializer>
