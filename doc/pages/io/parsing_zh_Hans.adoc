= 解析
解析是将序列化的 JSON 文本验证并分解为元素的过程。该库提供以下函数和类型以协助解析：

.解析函数与类型
|===
|名称e|描述

| <<ref_basic_parser>>
| 一种 SAX 推送解析器实现，将序列化的 JSON 文本转换为对用户提供处理器的成员函数调用序列。这允许为内存中文档表示实现自定义行为。

| <<ref_parse_options>>
| 用于选择解析期间启用哪些扩展的结构体。

| <<ref_parse>>
| 解析包含完整序列化 JSON 文本的字符串，并返回一个 <<ref_value>>。

| <<ref_parser>>
| 一种有状态的 DOM 解析器对象，可用于高效解析一系列包含在单个连续字符缓冲区中的 JSON 文本，每个结果返回为 <<ref_value>>。

| <<ref_stream_parser>>
| 一种有状态的 DOM 解析器对象，可用于增量高效解析一系列 JSON 文本，每个结果返回为 <<ref_value>>。

| <<ref_value_stack>>
| 用于高效构建 <<ref_value>> 的低级基础组件。解析器在内部使用此组件，用户也可用它适配外部解析器以生成此库的容器。
|===

== 解析器
<<ref_parser>> 和 <<ref_stream_parser>> 实例提供超越 <<ref_parse>> 自由函数的功能：

* 更精细的内存控制
* 流式 API，增量解析输入 JSON
* 解析多个 JSON 文本时性能更优
* 忽略 JSON 文本结束后的非 JSON 内容

解析器实现使用临时存储空间在解析期间累积值。使用 <<ref_parse>> 自由函数时，此存储空间在每次调用中分配释放。但通过声明 <<ref_parser>> 或 <<ref_stream_parser>> 实例，解析多个 JSON 文本时可复用此临时存储，减少动态内存分配总数。

使用 <<ref_parser>> 需声明实例，然后调用一次 <<ref_parser_write>> 传入包含输入 JSON 的缓冲区，最后调用 <<ref_parser_release>> 在成功时获取结果 <<ref_value>> 的所有权。此示例将解析器实例持久化为类成员以跨调用复用：

== 流式解析器
<<ref_stream_parser>> 实现了 https://en.wikipedia.org/wiki/Online_algorithm[__流式算法__]；它允许使用一个或多个连续字符缓冲区增量处理大型 JSON 输入。整个输入 JSON 无需一次性加载到内存中。网络服务器可使用流式接口以固定大小处理传入的 JSON，具有以下优势：

* 每个 I/O 周期的 CPU 消耗有界
* 每个 I/O 周期的内存消耗有界
* 减少抖动、不公平性和延迟
* 处理完整输入所需总内存更少

使用 <<ref_stream_parser>> 需声明实例，然后调用零次或多次 <<ref_stream_parser_write>> 传入连续的输入 JSON 缓冲区。无更多缓冲区时调用 <<ref_stream_parser_finish>>。若解析完成，则成功调用 `write` 或 `finish` 后 <<ref_stream_parser_done>> 函数返回 `true`。

== 自定义解析器
希望实现自定义解析策略的用户可创建与 <<ref_basic_parser>> 实例配合使用的处理器。该处理器需实现 SAX 事件接口要求的函数签名。<<examples_validate>> 示例中定义的 "null" 解析器会丢弃解析结果，用于实现验证 JSON 文本有效性的函数。
