== 使用分配器构造

[#author .author]#为了支持已经在使用多态分配器的代码库，本库中的# +
[#revdate]#容器支持++{++std++_++uses++_++allocator}构造。对于#

[[content]]
link:#ref_array[++[++ref++_++array++]++]、link:#ref_object[++[++ref++_++object++]++]、link:#ref_string[++[++ref++_++string++]++]和link:#ref_value[++[++ref++_++value++]++]：

* 嵌套类型`allocator++_++type`是++{++ref++_++polymorphic++_++allocator}的别名。
* 所有接受link:#ref_storage_ptr[++[++ref++_++storage++_++ptr++]++]的符合条件的构造函数，也将在相同的参数位置接受一个++{++ref++_++polymorphic++_++allocator}的实例。
* 成员函数`get++_++allocator`返回一个由容器使用的++{++ref++_++memory++_++resource}构造的++{++ref++_++polymorphic++_++allocator}实例。该内存资源的所有权不会被转移。

实际上，这意味着当库容器类型被用于一个使用多态分配器的标准容器中时，该分配器将传播到JSON类型。例如：

[source,highlight]
----
Unresolved directive in tmpzekv2frc.adoc - include::../../../test/doc_uses_allocator.cpp[tag=doc_uses_allocator_1,indent=0]
----

库容器可以从多态分配器构造：

[source,highlight]
----
Unresolved directive in tmpzekv2frc.adoc - include::../../../test/doc_uses_allocator.cpp[tag=doc_uses_allocator_2,indent=0]
----

多态分配器被递归传播。子元素的子元素将使用与父元素相同的内存资源。
